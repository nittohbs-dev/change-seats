# 機能一覧

更新日：2026-10-26。既存機能の確認対象：`origin/main` の `f2fb79c`。追加予定は未実装。

既存19機能、追加予定5機能、合計24機能。共通機能は複数画面から利用しても1機能として数える。

[画面一覧](screen-list.md)・[テーブル一覧](table-list.md)・[ER図](er-diagram.md)

| F-02 | アカウント登録 | 既存 | 利用者IDとパスワードを登録する。 | S-02 |

| F-07 | 2D座席図表示 | 既存・改修予定 | 座席の配置と着席状況を2Dで表示する。 | S-03、S-04、S-07 |

| F-20 | モデルアップロード | 追加予定 | 管理者が画面からモデルファイルをアップロードする。 | S-07 |

F-14は管理画面の手動実行に加え、日本時間0時の自動実行と起動時の補正を含む。既存・改修予定は、有効なレイアウトの選択や反映通知への対応を予定している機能。
