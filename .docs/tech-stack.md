# 技術スタック

更新日：2026-10-26。

席替えアプリは、バックエンドをJava、フロントエンドをHTML・CSS・JavaScriptで構成する。モデルのアップロード・自動抽出は追加予定の機能。

| 区分 | 採用技術 | 用途 |
|---|---|---|
| フロントエンド | HTML・CSS・JavaScript | 画面表示、入力、アップロード、API通信 |
| 3D表示 | Three.js | オフィスモデル・分身の表示、視点操作、プレビュー |
| バックエンド | Java 21以上・Spring Boot | 業務処理、API、アップロード受付、抽出処理の実行管理 |
| 認証・権限管理 | Spring Security | ログイン、パスワード認証、管理者権限 |
| DBアクセス | Spring Data JPA | データの検索・登録・更新・削除 |
| データベース | PostgreSQL | アカウント、座席、着席情報、レイアウト情報の保存 |
| モデル変換・座標抽出 | Blender・Python | バックエンド側で表示用GLB・座席座標・家具配置を生成 |
| 画面同期 | SSE | 座席やレイアウトの変更を各画面へ通知 |
| ファイル保存 | サーバーのファイル領域 | 元モデル、生成したGLB・JSONを保存 |
| ビルド・依存管理 | Maven | Javaアプリのビルドとライブラリ管理 |

モデル変換・座標抽出はバックエンド側の処理とする。Javaがアップロード受付・ファイル保存・処理の実行管理・結果保存を担当し、Blender上のPythonが変換と抽出を担当する。ブラウザはファイル送信、処理状況の表示、生成結果のプレビューを担当する。
